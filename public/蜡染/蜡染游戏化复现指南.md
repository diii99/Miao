# 蜡染教程：逐帧拆解与游戏化复现指南

**源视频：** [`蜡染教程.mp4`](蜡染教程.mp4)

**时长：** 202.4 秒；1920 × 1080；30 fps
**分析方法：** 全片以 2 秒间隔制作 102 张带时间码的接触表，并针对动作变化和字幕逐段复核。接触表在 [`analysis_frames/`](analysis_frames/)；复核脚本是 [`../../scripts/analyze_wax_dye_video.py`](../../scripts/analyze_wax_dye_video.py)。

> 范围说明：本指南严格区分「视频直接展示」与「游戏实现建议」。视频展示了上蜡、靛蓝浸染、空气氧化和再次复染；**没有展示脱蜡、清洗或晾干的具体操作**，因此不能把这些步骤当作本片的已证实流程。

## 一句话机制

把**需要保留为浅色**的图案区域用熔蜡封住；没有蜡的布会在靛蓝染缸中着色。刚从染缸取出的布先呈绿色，接触空气后逐渐氧化为蓝色；达到蓝色后继续复染来加深底色。最终的蓝底与受蜡保护的浅色花纹形成蜡染效果。

## 全流程状态机

```text
准备白布 → 预热/蘸蜡 → 试画并掌握蜡刀 → 描边 → 封闭并填蜡
     → 完整上蜡图案 → 靛蓝浸泡（约20分钟） → 提起氧化（绿→蓝）
     → 复染加深 → 成品展示
```

游戏中应把「布」当作核心状态对象：

| 状态字段 | 初始值 | 玩家操作后的变化 | 可见反馈 |
| --- | --- | --- | --- |
| `waxCoverage` | 0 | 描边、点蜡、填蜡后增加 | 琥珀色、略有光泽的蜡线/蜡面 |
| `sealedRegions` | 空 | 闭合轮廓后可填充 | 该区域进入“留白保护”状态 |
| `dyePasses` | 0 | 每次完整浸染并氧化后 +1 | 未封蜡区域由浅绿转更深的靛蓝 |
| `oxidation` | 0 | 离开染液、暴露在空气中上升 | 布从绿色平滑过渡到蓝色 |
| `patternScore` | 0 | 线条连续、封闭、无漏蜡时提高 | 结算时浅色图案边界更清楚 |

## 视频逐段与关键步骤

### 0. 开场与工具/布料建立

- **视频证据：** 00:00–00:12；标题为“如何制作蜡染”，随后展示一张布与蜡刀。
- **玩家动作：** 把一张白色棉布铺平，选择蜡刀。
- **需要物品：** 未染浅色棉布、短竹柄蜡刀、平整工作台。
- **场景观感：** 俯拍桌面；布为自然米白色，有褶皱和毛边；工作台为深灰、带颜料/蜡痕的手作台。
- **交互/判定：** 布未铺平时只允许轻度移动；“抚平”后解锁画蜡。可用柔和的布料摩擦音和布面褶皱消失作反馈。

### 1. 预热并轻蘸蜡刀

- **视频证据：** 00:12–00:30。蜡刀在盛有褐色熔蜡的白底绿边碗中蘸取；字幕说明先让蜡刀升温，避免蜡液快速凝固。
- **玩家动作：** 将蜡刀靠近热蜡并停留至温度条就绪，再以**刀角**轻蘸。
- **需要物品：** 加热的蜡碗/蜡炉、熔蜡、蜡刀。
- **场景观感：** 白色搪瓷碗的绿边有旧蜡渍；液蜡是半透明深琥珀色；下方是有烟熏痕的加热装置。
- **交互/判定：**
  - 温度不足：笔尖出现颗粒状、断续的蜡线。
  - 蘸取过深：`waxLoad` 过高，下一步有溢蜡风险。
  - 正确：刀角蘸蜡、液面产生小涟漪，蜡刀获得可用的短暂“保温窗口”。

### 2. 控制蜡量与用刀方向

- **视频证据：** 00:30–01:20。先在碗边轻蹭去掉多余蜡液；蜡液会聚集在较低的一头。视频强调：若继续用聚蜡的一端画，线条会溢出；换另一头并留出蜡液流下的时间，可控制细线。随后演示点蜡与较大面积的加蜡。
- **玩家动作：** 从碗边“刮蜡”到目标负载；旋转蜡刀，选择细线端/控流端；以短按点蜡，长按并移动画线。
- **需要物品：** 蜡刀、热蜡碗、练习布。
- **场景观感：** 镜头近距离俯拍手和笔尖，蜡线呈湿润的棕金色，落到布上后渐失光泽。
- **交互/判定：**
  - `waxLoad` 过高 + 慢速画线 → 蜡液外溢，线宽超标。
  - `waxLoad` 合适 + 正确刀头 → 连续的细轮廓线。
  - 允许练习叶片、一小段弧线、三个点；练习成功才开放正式图案。

### 3. 描边优先，再封闭填蜡

- **视频证据：** 01:20–01:48。大面积可多蘸蜡直接填；但要**先画完线条再填蜡**，否则“框上的部分会渗出来”。
- **玩家动作：** 先沿铅笔稿绘制闭合外轮廓，再切换“填蜡”笔触涂满叶片或花瓣内部。
- **需要物品：** 有淡铅笔稿的布、蜡刀、热蜡碗。
- **场景观感：** 米白布上出现透明感的琥珀色轮廓；叶片内部的蜡面比细线更深、更厚。
- **交互/判定：**
  - 填蜡前轮廓未闭合：显示薄红色漏染预警，结算时该区域会有蓝色渗漏。
  - 轮廓闭合后填充：区域变为 `sealed`，染色阶段保持浅色。
  - 这是核心迷你游戏：让玩家建立“边界先于面积”的因果理解。

### 4. 按草图完成整张上蜡图案

- **视频证据：** 01:48–02:48。展示整张预先描有花叶、卷草、点纹的布；字幕说明可自行设计图案，也可使用已画好的图案；先画底稿/轮廓再上蜡。视频明确说明“画上蜡的地方是白色，没有蜡的地方就染上蓝色”。
- **玩家动作：** 在大画幅上依次处理主花、叶片、卷草、点纹和星点；完成每一组后进行覆盖率检查。
- **需要物品：** 描好底稿的棉布、蜡刀、热蜡碗、参考图案卡。
- **场景观感：** 俯拍全布，左上是蜡碗与工具；布上为大型圆形/花卉与延展枝叶构图，琥珀蜡纹逐渐覆盖浅色布。
- **交互/判定：**
  - 图案可用“自由画”或“辅助描摹”两种难度。
  - 检查器显示未封闭路径、断线和未覆盖的设计区域，但不自动修复。
  - 完成后要在染色前给出“保留浅色区域预览”。

### 5. 靛蓝浸染

- **视频证据：** 02:48–03:00。画好后将布放入染缸；字幕指示放进去浸泡 **20 分钟**。
- **玩家动作：** 戴手套抓住布的两端，将其完全压入靛蓝染液，维持浸泡计时或以游戏内时间压缩完成。
- **需要物品：** 靛蓝染缸、手套、蜡封布、竹竿。
- **场景观感：** 深色矩形木染缸，液面近黑蓝，缸沿沾染蓝色；旁边有一根横放的竹竿。刚出缸的布呈湿润绿色。
- **交互/判定：**
  - 布未完全浸没 → 下半部/折叠处染色不均，形成斑驳失败态。
  - 浸泡计时到达目标 → 允许提起，`dyePasses` 仍未结算，需氧化。
  - 不把“20 分钟”做成真实等待；用 20 秒可中断小任务或一次确认跳时表示工艺时间。

### 6. 提起、氧化、复染与成品

- **视频证据：** 03:00–03:22。20 分钟后取出，字幕说明刚取出是绿色；与空气接触氧化后慢慢变蓝；变蓝后还要再次放进染缸染色。最后展示蓝底、浅色花纹的成品。
- **玩家动作：** 将湿布挂到竹竿，等待氧化条走完；确认颜色变蓝后把布送回染缸进行复染；达到目标深度后进入成品展示。
- **需要物品：** 竹竿/晾挂架、已湿染的布、靛蓝染缸。
- **场景观感：** 布从青绿色逐步转为深靛蓝，水珠沿下摆滴落；受蜡保护的花叶与点纹保持浅色。最终为深蓝底上的大面积浅色植物纹样。
- **交互/判定：**
  - 氧化未完成就复染：下一次颜色加深效率降低，并提示“先与空气接触”。
  - 每次“浸染→氧化”循环使 `dyePasses` +1，背景更深；浅色图案仅取决于前面的封蜡质量。
  - 终局评分分为：图案完整度、封蜡严密度、靛蓝层次、操作节奏。

## 物品清单与资产职责

| 物品 | 视频中的职责 | 游戏中的可交互性 | 建议碰撞/动画 |
| --- | --- | --- | --- |
| 棉布 | 承载图案与染色 | 核心状态物件；可铺、画、浸、挂 | 布料软体或骨骼布；需可切换干/湿材质 |
| 蜡刀 | 蘸蜡、描线、点蜡、填蜡 | 高精度主工具 | 笔尖射线；根据速度和 `waxLoad` 改线宽 |
| 蜡碗/热源 | 维持蜡液可用温度 | 供给、刮除、预热 | 液体蜡高光；温度与蜡量 UI |
| 图案底稿 | 引导花叶和卷草布局 | 初学难度的描摹层 | 可开关的半透明辅助线 |
| 靛蓝染缸 | 为未封蜡区域着色 | 浸泡场景的核心交互 | 体积液体、布进入/离开触发染色 |
| 竹竿 | 挂起氧化中的布 | 氧化与展示锚点 | 布料约束点；滴水粒子 |
| 手套 | 取放湿布 | 防护提示或角色装备 | 可简化为第一人称手部状态 |

## Lux3D 生成记录与验收

- Lux3D 需要可公开访问的 HTTP(S) 图片 URL；本地 PNG 不可直接提交。
- 七个当前资产均采用**单图直接 Image-to-3D**，版本为 `G1-Turbo`、PBR GLB、目标 50,000 面；其单主体/干净背景输入不需要额外四视图补全。
- 可复现的上传、提交、轮询、下载脚本是 [`../../scripts/generate_wax_lux3d_models.py`](../../scripts/generate_wax_lux3d_models.py)；真实任务、输入 URL、输出 URL、文件大小与“已替换”的旧蜡刀记录在 [`game-assets/lux3d-manifest.json`](game-assets/lux3d-manifest.json)。
- 蜡刀曾先按错误的“储蜡尖嘴”生成；已按截图重新制作扁平三角铜头参考图，并以新模型覆盖 `01-wax-knife.glb`。旧任务只保留在 manifest 中用于溯源，标记为 `superseded`。
- 结构验收：7 个 GLB 的文件头均为 glTF 2.0，声明长度等于实际文件长度，且每个都含至少一个网格、材质与两张纹理。

## 实现边界与下一步

1. 使用带透明/干净背景的单件 3D 道具；不要将整段真人操作或复杂工作台直接转成一个不可交互的整体模型。
2. 布料应作为“可变化材质”的物件：至少提供 `raw`、`waxed`、`wet-green`、`oxidized-indigo`、`finished` 五种状态，而非为每个状态复制独立逻辑。
3. 蜡的高光、湿布滴水、靛蓝氧化颜色过渡应由运行时材质/粒子系统完成；GLB 只提供基础网格和纹理。
4. 模型已保存到 `game-assets/3d/`；接入游戏引擎后，优先进行碰撞体、布料锚点、移动端加载体积和材质状态切换的运行时验收。
