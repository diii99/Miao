# 百米长桌宴 · 篝火视频接入预留版

这是从 `miao-feast-demo-centered` 完整保存出的独立副本。原居中版不会再被本文件夹内的后续视频改造影响。

本文件夹已经预留 `video/` 目录，用于接入“苗族夜晚篝火芦笙舞”视频。视频到位前，现有页面行为与居中版完全一致。

本版使用重新生成的完整长桌环境图，以及十二项统一顶视角、统一青花/铜器、统一暗夜暖光的餐食与场景素材。

## 运行

在本目录打开终端并执行：

```bash
python3 -m http.server 4177
```

然后访问：

```text
http://127.0.0.1:4177/
```

也可以直接双击 `index.html` 预览；使用本地静态服务时，浏览器兼容性更稳定。
