# 篝火歌堂视频素材放置说明

请把最终视频放在本目录，并命名为：

```text
miao-bonfire-lusheng.mp4
```

推荐规格：

- 格式：MP4
- 视频编码：H.264
- 音频编码：AAC
- 移动端优先：1080 × 1920（9:16 竖屏）
- 也可使用：1920 × 1080（16:9 横屏，页面将完整显示并留暗色边）
- 建议时长：15—45 秒
- 建议大小：50 MB 以内
- 保留芦笙、铜鼓与篝火现场声；避免过响的背景音乐
- 请确保素材具有可用于本项目的授权，且无第三方水印

可选封面图命名：

```text
miao-bonfire-lusheng-poster.jpg
```

计划接入流程：

1. 用户打开“篝火歌堂”展签。
2. 底部按钮改为“收起展签 · 观看篝火芦笙舞”。
3. 点击后展签收起，并打开沉浸式视频层。
4. 因为播放由用户点击触发，可以直接带现场声音播放。
5. 视频结束或点击关闭后，返回长桌最末端，不丢失游席进度。
