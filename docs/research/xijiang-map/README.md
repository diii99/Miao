## 结论

建议把当前围绕中央广场布置的主题体验场景，逐步转为以真实河谷和聚落关系为基础的西江三维文化地图。先建立白水河、坡地聚落、跨河桥、沿河道路和山坡步道的空间骨架，再增加建筑细节、夜景与文化互动。

这是一项有实景依据的视觉还原计划。现有材料足以支持聚落形态和地标名录研究，但不足以宣称测绘级数字孪生：尚未获得带坐标的正式底图、完整桥梁编号位置、建筑轮廓和高程实测数据。

官方游线确认了观景台和西江苗族博物馆是不同节点，且有西门、大北门、小北门等入口与换乘节点；不能继续用一个迎宾寨门代表整个入园系统。来源详见证据文档 S01–S03。

## 实施前必须补齐

| 缺口 | 原因 | 补齐方式 |
| --- | --- | --- |
| 正式底图与坐标系统 | 照片与文字游线不能给出精确位置 | 获取景区导览原件或有授权的地理数据；记录版本、北向和比例尺 |
| 桥号与桥名对应 | 本轮仅有一号、四号桥的官方文字证据 | 桥头标牌、官方点位与多视角照片逐一匹配 |
| 高差和步道路网 | 山坡视觉高度不等于真实坡度 | 获取高程数据，补拍台阶、道路连接点和观景台位置 |
| 地标立面与尺寸 | 当前 GLB 的细节不能证明真实建筑身份 | 每个地标建立实拍、地址、立面和尺寸证据包 |
| 图片再利用权限 | 公开报道不等于可以作为项目纹理分发 | 仅保留来源链接；使用前另行取得许可或自摄 |

未补齐的点位保持“待定位”，不填造经纬度、距离、桥号或营业时间。
