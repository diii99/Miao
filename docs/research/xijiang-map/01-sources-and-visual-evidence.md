- 可见事实：灰黑屋顶在中部山坡密集成片；建筑顺坡层叠，林木插入聚落；画面下部河道弯曲，近岸分布屋顶和树带；画面右侧有连续梯田，后部山脊被低云遮挡。

## 3. 空间事实转为设计约束

| 证据 | 可信程度 | 对地图的要求 |
| --- | --- | --- |
| 白水河穿过连片坡地村寨（S01、S04、S05、S06） | 高：报道与已看航拍相互支持 | 河流与坡地聚落共同构成骨架，不把河当广场旁边装饰 |
| 观景台与博物馆分别出现在官方游线（S02、S03） | 高：名称与节点独立；位置未测 | 分开地标身份、坐标和交互，不以博物馆代替观景台 |
| 一号和四号风雨桥是游线节点（S02） | 中高：官方文字，原站访问受限 | 先建待定位条目；本轮不宣称全部桥梁数量与顺序 |
| 文化院子、蜡染坊等存在（S06） | 高：场所类别；单体身份未核 | 可保留文化体验入口，具体工坊名称、立面与位置另核 |
| 村寨同时承担居住和旅游经营（S08） | 高：历史报道事实 | 展示生活街巷与普通住宅，避免把每栋房屋都做成展馆 |

S02 的游线可提炼为“西门—长肖—观景台—一号风雨桥—核心区—小北门—大北门”等游览关系，但箭头只是行程顺序，不意味着各节点间都有直接步行道路。必须分别核实步行、观光车和索道段。

## 4. 矛盾与不确定项

- 户数：S01 索引列 1468 户，S06 说 1000 多户，S08 历史报道为 1920 户。时间与统计边界不同，不能据此确定模型数量。
- 名称：不同官方游线有“西江讲堂/西江书局”“项圈广场/银项圈广场”“嘎哥/嘎歌”等差异。建立原文名称与日期字段，核实后再确定主名称，不能无证据合并。
- 桥梁：未获得最新完整桥号表；“风雨桥”与“接龙桥”不能未经核实就全量互换。
- 地形：没有带坐标底图、DEM 或实测高程；航拍不能提供准确北向、河流方向和坡度数值。
- 运营：官网索引在本轮出现 2026-08-13 观光车路线调整、2026-09-01 索道时间调整的公告标题，说明 S02 历史游线仍须更新；本轮未读取这些公告正文，不推测调整结果。
- 当前模型：存在细节丰富的 GLB，并不等于有西江实测建筑来源。`concepts/` 中的图片也不因文件名而成为实景证据。

## 5. 下一轮图片与数据采集单

1. 获取最新版景区导览原件，记录发布者、版本、图例、比例尺、北向和使用范围；手绘游览图不直接当测量底图。
2. 每座桥收集桥头铭牌、两个岸端和沿河视角；明确编号、别名、通行方式。
3. 为观景台与博物馆分别取得入口、完整立面和周围路口照片。
4. 吊脚楼采集平地与坡地类型，记录临坡支柱、屋面、走廊、背坡侧和石基；只对明确属于西江的实例建档。
5. 补拍普通住宅、滨河商铺、台阶、排水和田园边缘，不只收集盛装表演画面。
6. 每条记录包含 `id`、原始页、作者、发布日期、拍摄日期、机位、朝向、证据等级、使用许可和待核问题；未知值写“待核”，不猜测。
